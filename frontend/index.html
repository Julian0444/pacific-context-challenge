Ingest a document

Upload a document (.pdf, .txt, .md, .docx) with metadata. The backend verifies the file signature, extracts text, appends to the corpus, and rebuilds the index. Re-uploading identical content is rejected as a duplicate. Reindex takes 5–15 seconds.

Demo only: uploads are persisted to the local repo (corpora/<workspace>/ and artifacts/<workspace>/). Ephemeral hosting filesystems will lose uploaded docs on container restart. No delete or edit path — reindex is full-corpus and synchronous.
